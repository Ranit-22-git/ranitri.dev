## About

This repository holds the personal portfolio of **Ranit Ri**, a final-year
Biomedical Engineering student at Adamas University, Kolkata — focused on
biomedical instrumentation, medical imaging, and digital healthcare
technologies.

Instead of a generic template, the design borrows its visual language
directly from his own work: the hero section features an animated
**16-electrode EIT ring** (the same setup he built at NIT Durgapur), with a
live ECG-style waveform pulled through it — a nod to signals, not stock icons.

## Highlights

- 🧠 **Signature hero visual** — animated Electrical Impedance Tomography ring with sequential electrode pulses
- 🩺 **Real project data** — Health Monitoring, Breast Cancer Analysis, Gait Analysis studies, pulled straight from his CV
- 📊 **Animated CGPA chart** — semester-wise academic progress (8.20 → 9.67)
- 🕶️ **Glassmorphism UI** — soft blur panels, ambient particle background, aurora gradients
- 🖱️ **Micro-interactions** — custom cursor, magnetic buttons, scroll-reveal animations
- 📱 **Fully responsive** — desktop, tablet, and mobile, with a dedicated mobile nav

## Tech Stack

Pure front-end, zero build step, zero dependencies:

```
HTML5   →  semantic structure
CSS3    →  custom properties, glassmorphism, animations
JS      →  vanilla — canvas particles, IntersectionObserver, SVG generation
```

## Running Locally

No build tools, no npm install — just open it.

```bash
git clone https://github.com/Ranit-22-git/ranit-ri-portfolio.git
cd ranit-ri-portfolio
open index.html          # or double-click the file
```
